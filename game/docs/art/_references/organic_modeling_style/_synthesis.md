# organic_modeling_style

**Joan dijo:** "Vienen varios cosas modeladas: primero un limón, después una cebolla — me gusta el estilo de animación así. Aparecen unas flores moradas/violetas. Después un tipo moviendo una manta, animación de manta, como fluido, muy hipnotizante. Y después hay alguien trabajando como en plasticina — muy bonitos los diseños, no son de este mundo, son más abstractos. Ese tipo de dibujos también me gustaría para algún piso."

- **Idea**: secuencia de objetos modelados con look orgánico/abstracto — no realismo duro.
- **Colores**: depende del objeto (limón amarillo, cebolla, flor violeta, tela roja fluida, plasticina).
- **Forma**: formas suaves, redondeadas, sin dureza técnica.
- **Movimiento/Feel**: la manta/tela fluida es la pieza clave — movimiento hipnótico, tipo simulación de tela lenta.
- **Qué capturar**: el ESTILO ABSTRACTO/NO-REALISTA de la plasticina como candidato de dirección de arte para un piso — Joan lo marcó explícitamente ("para algún piso"), no solo mood.
- **Fuente**: reel Instagram, 5 frames. Origen: `frame_01871.png` (limón), `frame_01981.png` (cebolla), `frame_02031.png` (flor violeta), `frame_02151.png` (manta/tela fluida), `frame_02901.png` (plasticina/claymation).
