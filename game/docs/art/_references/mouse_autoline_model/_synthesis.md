# mouse_autoline_model

**Joan dijo:** "Después hay uno que pareciera que estuviera modelando solamente con el mouse, que pinta línea con negro, y después las modela automáticamente, dependiendo de dónde estén."

- **Idea**: dibujar líneas negras 2D con el mouse → generación automática de geometría 3D a partir de esas líneas.
- **Colores**: gris/neutro (etapa de modelado base), luego shading pintado final.
- **Forma**: técnica de auto-modelado desde dibujo de líneas.
- **Movimiento/Feel**: N/A — técnica de proceso.
- **Qué capturar**: el WORKFLOW — probable addon/técnica de Blender de "sketch to mesh". Útil como acelerador de producción de props/kit-bash.
- **Fuente**: reel Instagram, 2 frames. Origen: `frame_03019.png` (base modelada en nicho), `frame_03183.png` (etapa de texturizado/shading final).

**Aplicación posible**: acelerador de pipeline para props del `blender-asset-smith` — investigar qué addon/técnica es antes de adoptar.
