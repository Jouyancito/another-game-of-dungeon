# pixelart_ui

- **Qué capturar**: el PRINCIPIO — algunos elementos de UI/mundo pueden romper el estilo base en pixel art, elegidos caso a caso. No es "cambiar el inventario a pixel art", es "qué elementos puntuales SÍ conviene hacer en pixel art".
