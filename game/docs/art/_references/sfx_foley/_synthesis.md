# sfx_foley

**Joan dijo:** "Después viene un tipo grabando como un mapa, lo que está haciendo es hacer los sonidos del juego. No solo quizás también podríamos trabajar en algunos sonidos así, que sean fáciles de reproducir, onda, abriendo un diario, abriendo un cuaderno, moviendo una hoja, la naturaleza — ese tipo de cosas también podríamos verlo."

- **Idea**: foley casero para sonidos de juego — objetos cotidianos (libro, cuaderno, hoja) grabados directamente.
- **Colores/Forma**: N/A — referencia de proceso de audio, no visual.
- **Movimiento/Feel**: sonidos orgánicos, no sintetizados.
- **Qué capturar**: la TÉCNICA de foley barato/reproducible — relevante porque el audio actual del juego (PR #67) es placeholder sintetizado por Python (`tools/audio/gen_placeholder_sfx.py`). Esto es una vía alternativa/complementaria de bajo costo para SFX reales.
- **Fuente**: reel Instagram. Frame origen: `frame_01179.png`.

**Aplicación posible**: siguiente paso de audio real post-placeholder — foley con objetos físicos (diario, hoja, ambientes naturales).
